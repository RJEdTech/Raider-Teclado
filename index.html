Class leaderboard · for the teacher

There is no server and no sign-in, so scores do not gather themselves. Have students paste their score code into a Canvas assignment or a Teams message, then paste the whole pile in here. One code per line; extra text around them is ignored.

A note on ranking a class

Typing speed is a motor skill with an objective number, which is the one place a board like this is fairly safe — but a permanent public ranking is still the version of gamification with the weakest evidence behind it. Two ways to use this that keep the fun without the floor falling out for the slowest typist: run it as a single-round arcade score that resets each time, or rank by gain over a student’s own first score rather than raw speed. Every student’s personal best is already tracked privately on their own machine, with no ranking at all.

Turning the layout on

Switch between English and Spanish: Windows + Space. The indicator by the clock flips between ENG and ESP.

The accent key does nothing at first — that is correct. [ sends ´ and waits. The accent appears when you press the vowel. To type a bare ´, press [ then Space.
